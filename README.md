# Huawei Health — публичная интеграция Home Assistant

Неофициальный форк [and7ey/huawei_health](https://github.com/and7ey/huawei_health), MIT. Локальная версия 1.0.19 — кандидат для проверки, не официальный релиз upstream.

Интеграция получает данные через API Huawei Health с авторизацией аккаунта пользователя.

## Состав

- Авторизация Huawei ID через браузер и сохранение/обновление сессии Home Assistant.
- Получение данных здоровья и записанных тренировок MotionPath.
- Исправленное отображение длительности записанных тренировок.
- Локальный экспорт GPX с GPS и TCX с GPS или без него.
- Каталог видов тренировок; пульс в TCX только при подтверждаемых абсолютных временных метках. Относительные индексы не угадываются.
- Обезличенная диагностика целостности установки.

**Модулей сторонней синхронизации и автоматической выгрузки здесь нет.** Личные аккаунты, токены, диагностические выгрузки пользователя и данные тренировок не включены.

## Установка

Папку `custom_components/huawei_health` скопировать в `/config/custom_components/`, затем перезапустить Home Assistant. Добавить Huawei Health в разделе устройств и служб. Для способа входа см. также исходную документацию upstream.

При обновлении существующей интеграции не удалять config entry и `.storage`. Эта публичная сборка не предназначена для наложения поверх расширенного приватного комплекта: такое смешивание не удалит оставшиеся приватные файлы.

Для HACS после публикации и слияния ветки в собственном форке: добавить URL форка как пользовательский репозиторий категории Integration. Приём HACS и реальная установка из форка ещё не проверены.

## Локальный экспорт

`huawei_health.export_gpx` — маршруты GPS, `huawei_health.export_tcx` — TCX с опциональным маршрутом. Параметр `day: YYYY-MM-DD`, при нескольких аккаунтах также `entry_id`. Файлы содержат чувствительные данные и сохраняются локально в `/config/huawei_health_exports/`.

TCX использует итоговую дистанцию и активную длительность Huawei. Нет искусственных координат, дистанционной кривой и интерполяции пульса. Отсутствующая дистанция и калории — обязательный TCX нулевой sentinel, не измерение. Пульс `h-r` с неоднозначным временем пропускается.

## Публикация через Codespaces

Файл `publish_codespaces.sh` предназначен только для данного публичного пакета. Он проверяет контрольные суммы и состав, показывает GitHub-аккаунт, требует `PUBLISH`, создаёт или проверяет форк `and7ey/huawei_health`, берёт чистую upstream-базу и отправляет изменения в отдельную ветку **вашего форка**. Не делает merge, upstream PR или релиз. Сам скрипт, архив и контрольные суммы не отправляются в репозиторий.

Использовать только с проверенным публичным ZIP. Секреты скрипту передавать не нужно. Для GitHub CLI необходим доступ к созданию форка и push; ограниченный Codespaces-токен может потребовать отдельной авторизации `gh auth login`.
